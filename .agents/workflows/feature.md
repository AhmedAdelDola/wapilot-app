# WaPilot Feature Workflow

1. Read the applicable rules and project knowledge.
2. Inspect the relevant source files.
3. Search for an existing implementation or pattern.
4. State a concise implementation plan before non-trivial changes.
5. Implement the smallest clean solution.
6. Reuse existing components, services, store patterns, and utilities.
7. Check TypeScript and relevant tests.
8. Review the final diff for architecture, performance, security, and regressions.
9. Report changed files, verification performed, and remaining risks.
