# WaPilot Bug Fix

1. Reproduce or trace the failure.
2. Identify the root cause.
3. Search for the same failure mode elsewhere.
4. Implement the smallest correct fix.
5. Add regression coverage when practical.
6. Run relevant checks.
7. Review the diff for side effects.
8. Report the root cause, fix, and verification.
