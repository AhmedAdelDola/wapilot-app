# WaPilot Code Review

Review the current diff for:

- correctness
- architecture
- SOLID
- clean code
- TypeScript safety
- React Native rendering/lifecycle issues
- API and realtime behavior
- performance
- security
- error handling
- test coverage
- unnecessary complexity

Identify concrete issues and their impact.

Do not approve code merely because it builds.
